# Epic Corporations logo fonts

Web fonts used to recreate the lettering of the Epic corporation cards
(see `src/styles/epic.less`). Files come from the Fontsource npm packages
(latin subset, woff2). The Epic logos also use the Eternity fonts in `assets/eternity/fonts`.
