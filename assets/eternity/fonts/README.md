# Eternity corporation logo fonts

Web fonts used to recreate the lettering of the Eternity corporation cards
(see `src/styles/eternity.less`). Files come from the Fontsource npm packages
(latin subset, woff2).

| Font | License |
|---|---|
| Ubuntu | Ubuntu Font Licence 1.0 |
| Tinos, Baloo 2, Archivo Black, Fjalla One, Exo 2, Playfair Display | SIL Open Font License 1.1 |

The Prototype font used by some logos is the game's own (`assets/Prototype.ttf`).
